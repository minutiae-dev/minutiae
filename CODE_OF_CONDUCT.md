# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep discussion about the work.
Harassment, personal attacks and discriminatory language are not welcome in
issues, pull requests or anywhere else the project meets.

Report unacceptable behaviour privately through GitHub
(<https://github.com/minutiae-app/minutiae/security/advisories/new>) or by
contacting a maintainer. Reports are handled confidentially.
